🚀 如何讓兩支手機同時打開使用？

  1. 把這份單一檔案儲存為 index.html（或改名為 couple.html 放在你原本網站同一個資料夾下）。
  2. 上傳到你的 GitHub Pages、Netlify 或 Firebase Hosting。
  3. 將網址用 LINE 傳給老婆：
    • 老婆手機打開切換為 「👩🏻 老婆派單」
    • 你的手機打開切換為 「👨🏻 老公接單」（系統會自動記住各自的身分！）

📱 加入手機桌面（變身原生 App）

  • iPhone (Safari)：點底部中間「分享」按鈕 ➔ 選擇「加入主畫面」。
  • Android (Chrome)：點右上角選單 ➔ 選擇「加到主畫面」。
